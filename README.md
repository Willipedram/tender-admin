# سامانه ثبت شناسه شرکت

این مخزن یک برنامهٔ PHP تک‌صفحه‌ای برای ثبت شناسهٔ شرکت‌ها، مدیریت تأیید هویت و ارائهٔ فایل‌های قابل دانلود است. رابط کاربری کاملاً فارسی بوده و با Bootstrap 5 طراحی شده است.

## ساختار کلی پروژه

```
Woo-admin/
├── admin.php           # پنل مدیریت با امکان ذخیره تنظیمات و تغییر وضعیت شرکت‌ها
├── config.php          # تنظیمات اتصال پایگاه‌داده و ساخت جداول موردنیاز
├── download.php        # فرم دریافت لینک دانلود برای شرکت‌های تأیید شده
├── includes/
│   └── helpers.php     # توابع مشترک برای پاک‌سازی ورودی و منطق قابل‌آزمایش
├── index.php           # صفحهٔ فرود با لینک‌های دسترسی به بخش‌های مختلف
├── register.php        # فرم ثبت شناسهٔ شرکت و ثبت اطلاعات در پایگاه‌داده
└── tests/
    └── run.php         # مجموعه تست‌های خودکار برای توابع هسته‌ای
```

## پیش‌نیازها

- PHP 8.1 یا جدیدتر با اکستنشن `mysqli`
- پایگاه‌دادهٔ MySQL یا MariaDB
- دسترسی به خط فرمان برای اجرای تست‌ها

## راه‌اندازی پایگاه‌داده

۱. اطلاعات اتصال به پایگاه‌داده را در فایل `config.php` ویرایش کنید.
۲. با اولین بار بارگذاری هر صفحهٔ PHP، در صورت نبود جداول، جداول `companies` و `settings` به‌طور خودکار ساخته می‌شوند.

### جداول پایگاه‌داده

#### companies
| ستون | نوع | توضیح |
|------|-----|--------|
| id | INT AUTO_INCREMENT | شناسهٔ داخلی سیستم |
| company_id | BIGINT | شناسهٔ وارد شده توسط کاربر |
| company_name | VARCHAR(255) | نام شرکت |
| is_approved | TINYINT(1) | وضعیت تأیید (۰ یا ۱) |
| download_link | TEXT | لینک دانلود اختصاصی (در صورت نیاز) |
| ip_address | VARCHAR(45) | آدرس IP ثبت‌کننده |
| user_agent | TEXT | مرورگر یا عامل کاربری |
| created_at | TIMESTAMP | تاریخ ایجاد رکورد |

#### settings
| ستون | نوع | توضیح |
|------|-----|--------|
| id | INT AUTO_INCREMENT | شناسهٔ داخلی |
| expert_name | VARCHAR(255) | نام کارشناس احراز |
| expert_phone | VARCHAR(50) | شماره تماس کارشناس |
| download_link | TEXT | لینک فایل نهایی |
| created_at | TIMESTAMP | تاریخ ایجاد تنظیم |

## جریان کاری سیستم

1. کاربر در `register.php` شناسه و نام شرکت را وارد می‌کند.
2. اطلاعات پاک‌سازی شده و در جدول `companies` ذخیره می‌شود و پیام راهنما بر اساس آخرین تنظیمات نمایش داده می‌شود.
3. مدیر در `admin.php` با وارد کردن توکن به سیستم وارد می‌شود و می‌تواند:
   - اطلاعات تماس کارشناس و لینک دانلود را ثبت یا ویرایش کند.
   - وضعیت تأیید شرکت‌ها را تغییر دهد.
4. پس از تأیید، کاربر با وارد کردن شناسه در `download.php` لینک دانلود را مشاهده می‌کند.

## تست‌ها

تست‌های واحد در مسیر `tests/run.php` قرار دارند و توابع کلیدی موجود در `includes/helpers.php` را پوشش می‌دهند.

برای اجرای تست‌ها، در ترمینال دستور زیر را اجرا کنید:

```bash
php tests/run.php
```

در صورت موفقیت، پیام «All tests passed.» نمایش داده می‌شود.

## بهترین رویه‌های امنیتی پیشنهادی

- توکن مدیریت موجود در `admin.php` را با مقدار امن و غیرقابل حدس جایگزین کنید.
- فایل `config.php` را خارج از دسترس عمومی قرار دهید یا سطح دسترسی آن را محدود کنید.
- ارتباط سایت را با HTTPS ایمن کنید تا داده‌های فرم‌ها رمزنگاری شوند.
- برای جلوگیری از حملات CSRF از توکن‌های امنیتی در فرم‌های حساس استفاده کنید.
